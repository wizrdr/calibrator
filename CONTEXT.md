# Calibrator

Planning poker, который сохраняет индивидуальные голоса и после спринта сверяет их с фактом из Jira, чтобы показать, кто и насколько системно ошибается в оценках.

## Language

**Team**:
Группа людей с одним владельцем (лидом), в рамках которой копится история оценок и фактов.
_Avoid_: проект, воркспейс

**Member**:
Постоянный участник Team из ростера; к нему привязываются голоса из разных Session.
_Avoid_: пользователь, разработчик

**Session**:
Одно планирование: набор Issue, которые Team оценивает за один раз.
_Avoid_: комната, спринт, игра

**Participant**:
Человек, вошедший в конкретную Session по ссылке под своим именем. Может быть сопоставлен с Member.
_Avoid_: гость, юзер

**Issue**:
Единица работы с ключом из Jira, которую оценивают и по которой потом приходит Fact.
_Avoid_: задача, тикет, story

**Card**:
Значение, которое Participant показывает при голосовании: 1, 2, 3, 5, 8, 13, `?` или `☕`.
_Avoid_: оценка, балл

**Vote**:
Card, выбранная Participant по Issue в конкретном Round. Последняя выбранная до Reveal и есть Vote.
_Avoid_: ставка, ответ

**Round**:
Один цикл голосования по Issue. Первый Round отражает независимое мнение до обсуждения.
_Avoid_: попытка, итерация

**Reveal**:
Момент, когда голоса Round становятся видны всем; после него голосовать в этом Round нельзя.
_Avoid_: вскрытие, показ

**Final**:
Story points, которые Team согласовала по Issue после обсуждения.
_Avoid_: итоговая оценка, консенсус

**Fact**:
Что реально произошло с Issue по данным Jira: списанные часы (Time Spent), пройденные спринты, статус.
_Avoid_: actual, реальность

**Hours per SP**:
Сколько часов Fact в медиане приходится на один story point у этой Team. Абсолютный масштаб шкалы.
_Avoid_: скорость, velocity

**Implied SP**:
Сколько story points «стоила» Issue по Fact: часы, делённые на Hours per SP.
_Avoid_: фактическая оценка

**Bias**:
Системное смещение Member: во сколько раз его Vote в медиане отличается от Implied SP (или от Final). Измеряет голоса на колоде, а не восприятие: на Fibonacci «вдвое ниже» выглядит как ≈0.6×. Всегда относительно Team.
_Avoid_: точность, ошибка, погрешность

**Calibrated**:
Состояние Member, у которого доверительная полоса Bias накрывает 1.
_Avoid_: точный, хороший оценщик

**Coverage**:
Доля оценённых Issue, по которым есть Fact.
_Avoid_: полнота

**Carry-over**:
Issue, прожившая больше одного спринта.
_Avoid_: перенос, долг

**Team curve**:
Зависимость медианных часов Fact от Final по всем Issue команды.
_Avoid_: график, калибровочная кривая
